# FlashLearn - Flashcard Learning App

A simple, responsive flashcard learning application built using HTML, CSS, and JavaScript.

## Features

- Create and manage flashcards
- Flip cards to reveal answers
- Organize cards into decks
- Search flashcards
- Track studied and mastered cards
- Dark mode
- Local storage support
- Responsive design

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Installation

1. Clone this repository:

   git clone https://yashasgs514-source.github.io/my-test-project/?utm_source
2. Open the project folder.
3. Open index.html in your browser.

No dependencies or build tools required.

## Deployment

Enable GitHub Pages:

1. Open repository Settings.
2. Select Pages.
3. Choose Deploy from a branch.
4. Select main and / (root).
5. Save.

Your app will be available at:

https://yashasgs514-source.github.io/my-test-project/?utm_source
